# Changelog

All notable changes to raylibz are recorded here. The format follows [Keep a
Changelog](https://keepachangelog.com/en/1.1.0/); versions track raylib's major
and minor, and are not tagged yet (Live at Head: commits are the pins).

## 6.1.0-dev — unreleased

The package, its raw layer, and the shared layer the function wrappers will sit
on. Everything raylibz does is raylib's: raylib's own build script builds raylib
and translates `raylib.h`, `rcamera.h`, `raymath.h` and `rlgl.h`, and raylibz
puts a Zig face on those translations.

Added:

- `build.zig` / `build.zig.zon`: raylib as a dependency, pinned by commit
  (`mattneel/raylib` branch `zigpp` at `f0e501203d18f9c254fbabca353d08b8f4c698ac`,
  raylib 6.1-dev), every raylib build option forwarded unchanged, module
  `raylibz`, and the steps `test`, `parity` (with `-Dmodule=<file>`), `examples`
  and `run-<example>`.
- The raw layer: `raylibz.c`, `raylibz.raymath` and `raylibz.rlgl`, raylib's own
  translated modules as raylib publishes them.
- `src/cast.zig`: `as`, `asPtr`, `asArrayPtr`, `asLen`, `asSlice`, the text
  helpers, `assertLayout`, `assertEnumValues`, `assertFlagBits` and
  `NotWrapped`, with unit tests.
- `src/enums.zig`: raylib's 21 C enums as Zig enums with raylib's values, and
  `ConfigFlags` and `Gesture` as `packed struct`s of bools; every value and every
  bit asserted against raylib's translated constants at compile time.
- `src/types.zig`, `src/vector2.zig`, `src/vector3.zig`, `src/vector4.zig`,
  `src/matrix.zig`: all 35 of the pinned `raylib.h`'s structs mirrored, with
  raylib's field names, the `Texture2D`, `TextureCubemap`, `RenderTexture2D`,
  `Camera`, `Quaternion` and `ModelAnimPose` aliases, a layout assertion in every
  mirror, and `Color`'s 26 colour decls asserted against raylib's macros.
- The module files `core.zig`, `shapes.zig`, `textures.zig`, `text.zig`,
  `models.zig`, `audio.zig` and `math.zig`, each with its `not_wrapped` list, and
  `src/not_wrapped.zig` gathering them. The first wrappers are the ones
  `examples/basic_window.zig` needs: `initWindow`, `closeWindow`,
  `windowShouldClose`, `setTargetFPS`, `beginDrawing`, `endDrawing`,
  `clearBackground` and `drawText`.
- `src/raylibz.zig`: the root, with the raw layer, every type, enum and existing
  function re-exported flatly, and a test that fails if a module file declares
  something the root does not publish.
- `tests/functions.zig` (generated by `tools/gen_functions.py`): every RLAPI
  function of the pinned `raylib.h` with its module, and raymath's 146 RMAPI
  names.
- `tests/parity.zig`: the check that every raylib function is wrapped,
  re-exported or listed in `not_wrapped`, with `-Dmodule=<file>` for one module
  at a time, plus self-checks of the parity logic that pass.
- `tests/layout.zig`: every mirror referenced, so every layout assertion
  compiles.
- `examples/basic_window.zig`: raylib's `core_basic_window` in raylibz, with
  raylib's example notice kept, and `--frames N` so a machine can run a real
  window and exit.

Not yet: the bulk of the function wrappers (they are in progress, one module at a
time) and raymath's methods on the vector and matrix types. `zig build parity`
lists exactly what is missing, per module.
